# JOI Tools

情報オリンピック (JOI) の練習・考察用のブラウザアプリです。インストール不要の静的 Web アプリ（HTML / CSS / JavaScript のみ）で、データはすべてブラウザに自動保存されます。

## 機能

| タブ | できること |
| --- | --- |
| **コードテスト** | C++ / Python を複数のテストケースで実行し、期待出力と比較して **AC / WA / RE / TLE / CE** を判定。問題文の「入力例 / 出力例」をまとめて貼り付けて取り込み可能。WA の行は赤く表示。 |
| **メモ** | テキストメモ + 手書きキャンバス（ペン・消しゴム・線・矢印・四角・円・文字）。**番号付きノード**を置いて矢印でつなぐと、グラフや木がすぐ描けます（線はノードに吸着）。PNG 保存可。ペン入力時は手のひらを無視。 |
| **表** | DP 表などのグリッドを作成。範囲選択して色付け、0 / 1 始まりの添字切替、テキストから読み込み、スペース区切り / Markdown / CSV / C++ 配列 / Python リストでコピー。 |
| **手順** | アルゴリズムの手順を「1. / 1.1. / 2.」の番号付きアウトラインで整理。計算量の注記、実装済みチェック、BFS・DP・二分探索などのテンプレ、**コードにコメントとして挿入**。右側に計算量チェッカー（N を入れると各計算量が間に合うか判定）。 |
| **入力テンプレ** | よくある入力形式（数列・グリッド・グラフ・木・クエリ・複数ケース・EOF など）、出力形式、定番スニペットの C++ / Python コード。ワンクリックでエディタに挿入。 |

右上の「右に並べる」で 2 つのツールを同時表示できます（例: コードテスト + メモ）。

## 使い方

### 1. ローカルで使う（おすすめ・オフライン可）

Python 3 と g++ が入っているパソコンで:

```sh
python3 server.py          # Windows は start.bat をダブルクリックでも可
```

ブラウザで <http://localhost:8000> が開きます。手元の **g++ (-O2)** / **python** でコードを実行するので、インターネット不要・実行時間も正確です。

オプション: `--port 8080`（ポート変更）、`--no-browser`（ブラウザを開かない）

### 2. index.html を直接開く / GitHub Pages などで公開する

サーバーなしでも動きます。この場合のコード実行は:

- **C++** → [Wandbox](https://wandbox.org) の公開 API（インターネット経由。時間は通信込み）
- **Python** → ブラウザ内の [Pyodide](https://pyodide.org)（初回は読み込みに数秒）

実行環境はコードテスト画面のメニューで切り替えられます（「自動」なら ローカル → Wandbox / Pyodide の順に選択）。

## ショートカット

| キー | 動作 |
| --- | --- |
| `Ctrl+Enter` | 全テストケースを実行 |
| `Alt+1`〜`Alt+5` | タブ切り替え |
| `Ctrl+/` | 選択行のコメント切り替え（エディタ） |
| `Tab` / `Shift+Tab` | 字下げ / 字下げ解除（エディタ・手順） |
| `P` `E` `L` `A` `R` `O` `N` `T` | ペン / 消しゴム / 線 / 矢印 / 四角 / 円 / ノード / 文字（メモ） |
| `Ctrl+Z` / `Ctrl+Y` | 手書きの元に戻す / やり直し |

## 構成

```
index.html        画面
css/style.css     見た目（ライト / ダーク対応）
js/util.js        保存・ダイアログなど共通処理
js/editor.js      コードエディタ（色分け・自動インデント）
js/runner.js      実行バックエンド（ローカル / Wandbox / Pyodide）と出力比較
js/codetest.js    コードテスト画面・サンプル取り込み
js/memo.js        メモ（テキスト + 手書き）
js/table.js       表
js/algo.js        手順・計算量チェッカー
js/templates.js   入力テンプレ集
js/app.js         タブ・分割表示・テーマ
server.py         ローカル実行サーバー（標準ライブラリのみ）
```

`server.py` は `127.0.0.1` でのみ待ち受け、他のサイトからの実行要求は拒否します。
