計算量チェッカー

目安: C++ で 1 秒あたり約 108 回の単純演算。Python は 10〜50 倍遅いと考える。

制約から逆算

N の上限許される計算量
≤ 10O(N!)
≤ 20O(2N), O(N·2N)
≤ 40O(2N/2) 半分全列挙
≤ 500O(N3)
≤ 5000O(N2)
≤ 2×105O(N log N), O(N√N)
≤ 107O(N)
≤ 1018O(log N), O(√N) は ≤1012

使い方

  • コードテスト: C++ / Python を複数のテストケースで実行し、期待出力と比較 (AC / WA / RE / TLE / CE)。Ctrl+Enter で全実行。「サンプル貼り付け」で問題文の入力例・出力例をまとめて取り込めます。
  • 実行環境:
    • ローカル: python3 server.py で起動して http://localhost:8000 を開くと、手元の g++ / python で実行（オフライン可・時間計測が正確）。
    • Wandbox: インターネット経由で C++ / Python を実行（時間は通信込み）。
    • ブラウザ内 Python: Pyodide でブラウザ内実行（初回は読み込みに数秒）。
  • メモ: テキストと手書き。ノードツールで番号付きの頂点を置き、線・矢印ツールで頂点どうしを結ぶとグラフや木が描けます。
  • 表: DP 表などを作成。範囲選択して色付け、各種形式でコピー。
  • 手順: アルゴリズムの手順を番号付きで整理。コードにコメントとして挿入も可。右側は計算量チェッカー。
  • 入力テンプレ: よくある入力形式の受け取り方。「エディタに挿入」でカーソル位置に入ります。
  • 右上の「右に並べる」で、2つのツールを同時に表示できます。
  • データはすべてこのブラウザ (localStorage) に自動保存されます。
  • ショートカット: Alt+1〜5 タブ切替、エディタで Ctrl+/ コメント切替、Tab/Shift+Tab 字下げ。
